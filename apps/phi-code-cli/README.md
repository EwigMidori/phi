# phi-code-cli

Thin binary entry for phi-code.

| Layer | Crate / module |
|-------|----------------|
| Product runtime | `phi-code-core` |
| TUI objects | `phi-code-ui` |
| Shell + panes | `shell`, `scrollback_pane`, `prompt_pane`, `turn_driver` |
| Terminal host | `main` (`run_terminal_host`) |

```bash
cargo run -p phi-code-cli
```
